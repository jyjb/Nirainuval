# NiraiNuval v1

## v1.0.0

This release consolidates the deployable Windows x64 parser package into
`release/v1/`.

Included:

- `nsdxn-v1-windows-x64.exe` — the Aingnyazhi-based parser executable;
- `NiraiNuval_NSDXN_v4.md` — the included NSDXN specification;
- `LICENSE`; and
- `VERSION_NOTES.md` with package scope and deployment guidance.

The package contains no build cache, test logs, editor packages, compiler
toolchain, or PowerShell wrapper. The executable is self-contained for the
supported Windows x64 validation workflow. Full language coverage and a
stable library API remain outside this v1 package.
